# Dashboard Financeiro de Condomínio

## Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de analisar as receitas e despesas de um condomínio residencial através do Power BI.

Os dados foram extraídos da plataforma da administradora do condomínio em arquivos XLS, tratados e modelados utilizando conceitos de modelagem dimensional (tabelas fato e dimensão).

O dashboard foi criado para fornecer uma visão financeira estratégica do condomínio, permitindo acompanhar:

- Receitas
- Despesas
- Saldo financeiro
- Categorias de gastos
- Evolução mensal
- Indicadores financeiros

---

## Objetivo

O principal objetivo deste projeto é aplicar conceitos de:

- Análise de Dados
- Power BI
- Modelagem de Dados
- ETL
- DAX
- Visualização de Dados

Além de servir como projeto de portfólio para demonstrar evolução prática na área de análise de dados.

---

## Interface do Dashboard

O dashboard foi desenvolvido utilizando uma interface executiva inspirada em painéis financeiros corporativos, contendo:

- Barra lateral de navegação
- Indicadores KPI
- Área de análise temporal
- Área de distribuição financeira
- Segmentação temporal
- Layout responsivo para análise gerencial
